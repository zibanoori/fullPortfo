# Full-Stack Portfolio

A responsive personal portfolio built with Python, Django, and modern frontend technologies.

## 🛠️ Tech Stack
-   **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
-   **Backend:** Python, Django, DRF
-   **Tools:** Git/GitHub, WebP Optimization

## ✨ Key Features
-   Dynamic static loading via Django's `{% static %}` tag
-   Mobile-first responsive design
-   Interactive Vanilla JS carousel & smooth navigation
-   Optimized assets for performance and SEO

## 📂 Project Structure
```text
fullPortfo/
├── backend/            # Django settings & logic
├── static/assets/      # CSS, JS, Images (WebP/SVG)
├── template/           # HTML templates
└── manage.py
```
