#  Ziba Noori - Full-Stack Portfolio

Welcome to my personal portfolio project! This website showcases my journey as a Full-Stack Developer, blending frontend creativity with backend logic using Python and Django.

> *"Every line of code is a brick in the bridge to my future."*

## 🚀 About This Project
This is a responsive, dynamic portfolio website built from scratch. It demonstrates my skills in:
-   **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, DOM Manipulation
-   **Backend:** Python, Django Framework, Django REST Framework
-   **Tools:** Git/GitHub, Static Asset Management, Responsive Design

The project features a clean UI, interactive project cards, and a fully integrated static file structure for optimal performance.

## 🛠️ Tech Stack
| Category       | Technologies Used                     |

| **Frontend**   | HTML5, CSS3, JS (ES6+), Bootstrap 5   |
| **Backend**    | Python, Django, DRF                   |

| **Version Ctrl**| Git & GitHub                          |

## 📂 Project Structure
```text
fullPortfo/
├── backend/            # Django settings & app logic
├── static/assets/      # CSS, JS, Images (WebP/SVG)
├── template/           # HTML templates with {% static %} tags
├── manage.py           # Django management script
└── README.md           # You are here!
```


## ✨ Key Features
-   **Dynamic Static Loading:** All assets served via Django's `{% static %}` tag.
-   **Responsive Design:** Mobile-first approach using Bootstrap 5.
-   **Interactive UI:** Vanilla JS carousel and smooth scrolling navigation.
-   **Optimized Assets:** WebP images for faster loading and better SEO.
